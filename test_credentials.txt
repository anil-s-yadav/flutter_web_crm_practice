// Here are the best free hosting options for your **Node.js Express API** and **MySQL Database**:

### Option 1: Render + TiDB Cloud (Recommended Free Combination)

#### 1. Node.js Express API: **Render** ([render.com](https://render.com))
- **Free Tier:** 512 MB RAM, free SSL/HTTPS, automatic deployments from GitHub.
- **Note:** Free web services sleep after 15 minutes of inactivity and wake up automatically on the next incoming request (takes ~15–30 seconds to wake up).

#### 2. MySQL Database: **TiDB Cloud** ([tidbcloud.com](https://tidbcloud.com))
- **Free Tier:** Serverless MySQL-compatible database with **5 GB free storage** (Always Free, doesn't sleep).
- Fully compatible with `mysql2` driver used in your Node.js backend.

### Option 2: Railway ([railway.app](https://railway.app))
- **All-in-one:** Host both your **Node.js API** and **MySQL Database** together in one dashboard.
- **Free Tier:** Provides free monthly execution credits ($5 / 500 hours free per month).
- Easy 1-click deployment from GitHub.

### Option 3: Koyeb + Aiven / TiDB

#### Node.js API: **Koyeb** ([koyeb.com](https://www.koyeb.com))
- **Free Tier:** 512 MB RAM instance that **stays awake 24/7** (does not sleep after inactivity).
- Deploy directly from GitHub repository.

### Recommended Deployment Setup Summary

1. **Push your code to GitHub:**
   Make sure your `backend/` folder is committed to a GitHub repository.

2. **Set Environment Variables on Host:**
   Configure your production database credentials in your host environment:
   - `DB_HOST`
   - `DB_USER`
   - `DB_PASSWORD`
   - `DB_NAME`
   - `JWT_SECRET`
   - `PORT`

3. **Update Flutter Frontend Base URL:**
   Once hosted, update `static const String baseUrl = 'https://your-api.onrender.com/api';` in [api_client.dart](file:///d:/flutter_web_crm_practice/lib/api/api_client.dart#L7).
